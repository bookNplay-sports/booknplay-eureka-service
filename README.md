Eureka Server is the Service Discovery component of the BookNPlay Sports Turf Booking Platform. It allows all microservices to register themselves and discover other registered services dynamically. It maintains a registry of available services, enabling communication between microservices without hardcoding service URLs. It helps manage service registration and discovery across the microservices architecture.

Technology Stack: Java 21, Spring Boot, Spring Cloud Netflix Eureka Server, and Maven.

Configuration: Service Name: eureka-server | Port: 8761

Eureka Dashboard: http://localhost:8761

Eureka Server acts as the central service registry for the BookNPlay microservices architecture.
